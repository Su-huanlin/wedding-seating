# 婚宴排桌 囍

自己婚礼排婚宴桌位时，Excel 来回改、纸上画圈圈，既容易乱也难给家人看清楚。

于是做了这个小工具：**打开网页就能排桌**——导入名单、在厅纸上拖桌子和来宾，排满意了再导出平面图或 PDF 去打印。中式、西式厅纸都有，多个厅也能分开排。

> 没有账号，没有后台。数据只存在你自己的浏览器里，适合自己或司仪本地用。

**直接用：** [https://wedding-seating-lilac.vercel.app/](https://wedding-seating-lilac.vercel.app/)  
**源码：** [GitHub](https://github.com/Su-huanlin/wedding-seating)

---

## 它能做什么

- 从 Excel 导入来宾（桌号、姓名、人数、备注）
- 在厅纸上拖桌、拖人入座，支持多厅
- 中式 / 西式两套底图，左右桌数、每桌人数可调
- 导出 PNG / PDF（可选纸张大小）、Excel 名单，也能直接打印查桌表
- 撤销重做、锁厅锁桌，手滑了也不怕

手机也能打开看看、改一改；精细排桌、导出打印，还是电脑上更顺手。

---

## 怎么用（推荐路径）

### 1. 打开网页

点上面的公网地址即可，不用安装。

### 2. 准备名单

点顶部 **「下载模板」**，用 Excel / WPS 打开 `宴请名单模板.xlsx`。

按「一桌一块」填写就行：

| 桌号 | 姓名 | 人数 | 备注 |
|------|------|------|------|
| 1 | 赵先生 | 2 | 领导 |
| | 钱女士 | 1 | 领导 |
| | | *合计公式* | |
| | | | |
| 2 | 孙先生 | 1 | 朋友 |
| … | … | … | … |

小提示：

- **桌号**只写在该桌第一行，下面几行留空（模板里已合并）
- **人数**写这一家几位（夫妻填 2）；每桌最后一行会自动求和
- **备注**写关系：领导 / 朋友 / 家人 / 同学…
- 桌与桌之间 **空一行**
- 模板里有 16 桌示例，可改可删；「填写说明」表里还有几句对照

### 3. 导入

回到网页，点 **「导入 Excel」**，选填好的文件。

注意：再次导入会覆盖当前浏览器里的名单和桌位，重要文件请自己留备份。

### 4. 在厅纸上微调

- 顶栏切换 **中式 / 西式**，用下拉 **选厅**，可开新厅、调左右桌数
- 拖空白处平移画布，滚轮缩放
- 拖桌子挪位置，拖来宾芯片换座位
- 需要固定时点「锁桌 / 锁厅」
- `Ctrl+Z` / `Ctrl+Y` 撤销重做；`Delete` 删桌，`Ctrl+Delete` 删厅

### 5. 导出分享

点 **「导出」**：

- **PNG**：高清平面图，发群里挺方便  
- **PDF**：按厅分页，可选 A4～A2；人太多、字太小时会提醒你换大纸  
- **Excel**：带桌号的名单  
- **打印**：按桌查人用的表

## 数据存在哪儿？

存在你浏览器的 **localStorage** 里，不会上传到服务器。

所以：

- 换电脑、换浏览器、清理站点数据 → 本地排桌结果可能没了  
- 请保留好 Excel 源文件，排完及时导出 PNG / PDF 备份  

这是单人小工具的取舍：简单、隐私，但不做云同步。

## 本地跑一份（可选）

想改代码或离线开发时：

```bash
git clone https://github.com/Su-huanlin/wedding-seating.git
cd wedding-seating
npm install
npm run dev
```

浏览器打开终端里提示的地址（一般是 `http://localhost:5173/`）。

---

## 小限制

- 单厅最多 30 桌（左右各不超过 15）
- 桌特别多时，A4 可能看不清人名，听导出提示换 A3/A2 就好
- 不做登录、不做多人同时编辑
